# Da Pau Eating Experience 😋
> An Unbeaten Eating Experience

A Code::Blocks C terminal application game for me to practice writing C code and a fun side project at the same time.

## Play 🎮
- No built binaries yet so just download compile the project and enjoy!

## Features ✨
As of now here's some of the features currently implemented:
- Fully fledged snake game
- Uses a framebuffer for rendering on screen
- And more to come as i get better at this 😋

## Contributing 🤝
- If you want to contribute feel free to open a PR I'd love to learn and see where this game can improve!
